# The Centre For The Human Family

This is a Unity VR experience project showcasing Think's Round multicultural exhibits.



## Requirements

- Unity version [6000.0.37f1](https://unity.com/download) or newer.
- Windows or Mac PC.
- VR Headset.



## Getting Started

### Getting the code

Ensure you have [Git LFS](https://git-lfs.github.com/) installed:

`git lfs install`

Clone this repo:

`git clone https://github.com/Think-Round-Inc/The-Center-for-the-Human-Family.git`

## How to Run the Project

Project can be run in these ways; 

- Through in-editor using Unity Simulator.

- Through in-editor using a VR Headset connected via a Cable.

- Through a VR Headset, after project has been built. 

⚠️ Kindly note to add Scene `ParadiseExhibit` to SceneList and make the first scene before building to headset.
